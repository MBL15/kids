# Подбор методики преподавания (AHP)

Веб-приложение для ведения учеников, оценок по урокам и рекомендации методики обучения на основе упрощённой иерархии: важность критериев (шкала 2–5), матрица «методика × критерий» (2–5) и агрегирование оценок уроков. Бэкенд на Node.js хранит данные пользователей в JSON-файле.

## Возможности

- Регистрация и вход (JWT), данные изолированы по учётной записи
- Ученики: ФИО, заметки, уроки с датой и оценками по критериям (2–5)
- Правила: критерии, методики, важность и таблица подходящести
- Анализ: функциональная модель (F1–F6), глобальные приоритеты методик, рекомендация
- Визуализация: радары (Chart.js) — профиль успеваемости по критериям и доли приоритетов методик

## Требования

- [Node.js](https://nodejs.org/) 18+ (рекомендуется LTS)

## Установка и запуск

```bash
npm install
npm start
```

Сервер слушает порт из переменной `PORT` или **3000**. Если порт занят, автоматически перебираются следующие (до 30 попыток). **Откройте в браузере URL из консоли** (например `http://127.0.0.1:3000` или другой порт).

Режим с автоперезапуском при изменении `server.js`:

```bash
npm run dev
```

## Переменные окружения

| Переменная    | Описание                                      |
|---------------|-----------------------------------------------|
| `PORT`        | Порт HTTP-сервера (по умолчанию `3000`)       |
| `JWT_SECRET`  | Секрет подписи JWT (в продакшене задайте свой)|

## API (кратко)

- `POST /api/auth/register`, `POST /api/auth/login` — токен в ответе
- `GET /api/me`, `PUT /api/me` — загрузка и сохранение состояния (заголовок `Authorization: Bearer <token>`)
- Статика: `index.html`, `/css`, `/js`, `/vendor/chart.js` (из `node_modules`)

## Структура проекта

```
├── server.js              # Express + HTTP, раздача SPA и API
├── server/
│   ├── store.js           # Файловое хранилище пользователей
│   └── defaultUserState.js
├── data/                  # Создаётся при работе; store.json в .gitignore
├── js/
│   ├── app.js             # Клиентское приложение

│   ├── studentRadar.js    # Диаграммы Chart.js
│   └── analysis/          # Модели и алгоритмы рекомендации
├── css/styles.css
├── index.html
└── package.json
```

## Данные

Файл `data/store.json` создаётся локально и **не коммитится** (см. `.gitignore`). После клонирования репозитория достаточно запустить сервер и зарегистрировать пользователя.
