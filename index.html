Подбор методики преподавания (AHP)

Структура: авторизация → ученик → оценки уроков → подготовка данных → анализ → рекомендация

Авторизация

Бэкенд на Node.js: учётные записи и данные хранятся на сервере (файл data/store.json). Создайте аккаунт или войдите.

Ведение данных об ученике

Ввод ФИО и заметок; хранение в базе на сервере. Далее — оценки по урокам (критерии из настроек).

Список учеников

Имя Уроков Действия

Ученик

Профиль успеваемости (радар)

Средние баллы по критериям по всем занятиям (шкала 2–5). Наибольшие значения на лучах выделены синим, как на контрольной диаграмме.

Оценки по урокам (2–5)

Укажите дату занятия и баллы по каждому критерию по шкале 2–5; записи сохраняются на сервере в карточке ученика.

Запрос анализа и рекомендация

Анализ оценок выполняется по даталогической модели (какие данные связаны) и функциональной модели (какие функции преобразуют данные по шагам).
